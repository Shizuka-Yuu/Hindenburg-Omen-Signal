# Market Data Sync Tool

市場データおよびインデックス情報を定期的に収集し、Google スプレッドシートへ自動同期するためのツールです。

## 概要

本プロジェクトは、市場情報や各種指数データを外部ソースから自動的に収集し、Google Apps Script (GAS) のウェブアプリを経由して指定のスプレッドシートに記録する仕組みを提供します。

### システム構成

1. **データ収集スクリプト (`scrape.js`, `scrape_jpx.js`)**
   - 外部ソースから必要な各種指標・市場データを取得・整形します。
   - 取得したデータを JSON 形式に構造化し、GAS エンドポイントへ POST 送信します。
2. **GAS エンドポイント (`gas_endpoint.js`)**
   - 送信されたデータをスプレッドシートの指定シート（自動作成）に記録します。
   - 同一日のデータ重複を防ぐための自動上書きロジックが組み込まれています。
3. **自動実行ワークフロー (`.github/workflows/cron.yml`)**
   - GitHub Actions 上で毎日定期的にスクリプトを実行し、ハンズフリーでのログ収集を実現します。

## セットアップ手順

### 1. Google スプレッドシートおよび GAS の設定

1. 同期先のスプレッドシートを作成し、メニューの **「拡張機能」>「Apps Script」** を開きます。
2. エディタ内の既存コードを削除し、[gas_endpoint.js](file:///c:/Users/Yukie/Documents/Software/Hindenburg-Omen-Signal/gas_endpoint.js) の内容をすべて貼り付けます。
3. エディタ上で `setup` 関数を選択して実行し、アクセスの承認を行います（必要なシートが自動的に作成されます）。
4. 画面右上の **「デプロイ」>「新しいデプロイ」** をクリックします。
5. 以下の通り設定し、デプロイを行います：
   - 種類の選択：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 発行された **「ウェブアプリのURL」** をコピーします。

> [!TIP]
> すでにデプロイ済みの場合は、既存デプロイの編集より「新バージョン」を作成して適用することで、同じURLを使い続けることができます。

### 2. GitHub リポジトリの設定

1. GitHub リポジトリの **Settings** > **Secrets and variables** > **Actions** に移動します。
2. **Repository secrets** に新規登録を行います：
   - Name: `GAS_WEBAPP_URL`
   - Value: コピーした **「ウェブアプリのURL」**

### 3. ローカルテスト（動作確認）

ローカル環境でデータ取得と送信をテストする場合は、以下のコマンドを実行します。

```bash
# 依存関係のインストール
npm install

# 動作検証（GAS_WEBAPP_URL を設定するとスプレッドシートへ送信されます）
$env:GAS_WEBAPP_URL="<コピーしたGASのウェブアプリURL>"
node scrape_jpx.js
node scrape.js
```
